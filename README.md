> A premium, highly interactive, and immersive fan-made digital experience celebrating the legacy of 7-time Formula 1 World Champion Lewis Hamilton. Built using next-generation 3D rendering and motion libraries for a fully immersive web showcase.

---

## ✨ Features & Highlights

- **🛸 3D Interactive Helmet Presentation**: A detailed Lewis Hamilton helmet rendered dynamically in real-time using custom-engineered GLB assets.
- **⚡ Stylized Wireframe Reveal**: Dynamic timed reveal and scroll-reactive wireframe transitions powered by React Three Fiber and custom shaders.
- **🌌 Hyperspeed Ambient Background**: An immersive, high-performance particle/speed line background treatment that brings the thrill of F1 directly to the browser.
- **🎬 Cursor-Reactive Cinematic Depth**: Advanced mouse-tracking parallax and depth layering for a premium, tactile hero section.
- **📜 Ultra-Smooth Scroll Mechanics**: Integrated scroll-based text animations, elegant reveals, and momentum scroll powered by Lenis and GSAP.

---

## 🛠️ The Technology Stack

This application utilizes a modern, high-performance creative web stack to deliver desktop-class visual fidelity at 60fps:

- **Framework**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/) for robust, type-safe reactive UI components.
- **Build Tool**: [Vite](https://vite.dev/) for ultra-fast, modern module bundling and hot-reloading.
- **3D Rendering**: [Three.js](https://threejs.org/) + [React Three Fiber](https://r3f.docs.pmnd.rs/) + [Drei](https://github.com/pmndrs/drei) for declarative WebGL scene graph integration.
- **Motion & Timelines**: [GSAP (GreenSock)](https://gsap.com/) for precision-sequenced scroll triggers and interface micro-animations.
- **Scroll Engine**: [Lenis Scroll](https://lenis.darkroom.engineering/) for consistent, smooth inertial scroll behavior across all modern devices and platforms.
